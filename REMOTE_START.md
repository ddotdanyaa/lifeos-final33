# Удалённая сессия — начни отсюда

Этот файл существует ради одного: чтобы сессия с телефона за пять минут знала то, что здешняя
сессия узнавала неделю. Читается ПЕРВЫМ, до `CLAUDE.md`.

Состояние на 1 августа 2026.

---

## 1. Первые три команды

```bash
npm install
npm start          # http://127.0.0.1:4173 — ровно один сервер, лишние порты гасить
npm run verify
```

`npm run verify` сейчас **красный** — и это известно. Причина в §5.

## 3. Главное правило владельца

> **Зелёные тесты и работающий продукт — разные вещи.** Сейчас между ними разрыв.

Он проверил живую мысль про смену в такси: разбор существовал, отработал, вернул одну
бесполезную строку — а приборы показывали зелёное. Поэтому:

**Сценарии закрываются по одному, на его настоящих мыслях, до состояния «работает».**
Не по списку галочек, не «механизм есть».

блоками по именам функций.

## 7. Очередь работ

1. Прогнать пять непрогнанных спек, починить найденное.
2. Слить `state.improvements` из ветки агента.
3. Починить прибор живости → зелёный `verify`.
4. Промпт локальной модели под сценарий владельца: мысль о завтрашней смене → решение на
   сегодняшний вечер с вопросом, который закроет решение.
5. Сеть: запрос о прибыльных часах. **Упирается в тумблер приватности — решает владелец.**
6. Календарь: блок работы на завтра + предварительный доход.
7. Дальние сценарии из `Клауд.txt`: Decision Memory, Prediction, Personal Twin.

## 8. Ловушки, на которых уже теряли часы

- **`normalizeState` не спасает.** `commit()` рисует раньше, чем нормализация добавит поле.
  Новые поля проставлять **при создании объекта**.
- **Мёртвый код лежит непроверенным.** `store.getState()` был битым всегда и уронил экран при
  первом же вызове: путь не исполнялся, поэтому его не ловил никто. Включаешь мёртвый путь —
  читай его целиком.
- **`renderProposalPanelV2` (`app.js`) мёртвая и упадёт**: зовёт `renderProposalCard` и
  `renderRecommendedProposal`, которых в репозитории нет. Не «включать обратно».
- **Эмбеддинги отключены осознанно**, с числом: разделение смысла и шума 0.027. Возвращаться
  только с новым замером.
- **Правка UI → `node tools/build-public.mjs`**, иначе публичная сборка отстанет.
- **Гейты не ослаблять.** Контракт меняется только вместе с намеренным изменением продукта и с
  обоснованием в `IMPROVEMENT_LEDGER.md`.
- **Не коммить и не пушить без слова владельца.**
