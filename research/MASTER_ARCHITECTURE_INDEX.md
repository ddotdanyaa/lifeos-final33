# MASTER_ARCHITECTURE_INDEX — лучшие архитектурные модели

Для каждой подсистемы: лучшая модель из изученных проектов, кто её образцово реализует, и как
она проецируется на архитектуру LifeOS (vanilla JS / IndexedDB / 47 коллекций / proposal→receipt).
Здесь — модели (структура и потоки); конкретные алгоритмы — в `MASTER_ALGORITHM_INDEX.md`.

## 1. Память (memory)
- **Модель-эталон:** Mem0 — многоуровневая (профиль/сессия/агент), **ADD-only** (факты копятся,
  не перетираются), importance-scoring на выдаче, decay старого. Graphiti добавляет **би-темпоральность**
  (окно валидности + время ингеста) и **инвалидацию вместо удаления**.
- **Проекция LifeOS:** память = слой скоринга поверх артефактов/коллекций; новый факт = proposal;
  противоречие = supersede-цепочка (не delete), провенанс = source→note→receipt. Пакеты M1–M4.

## 2. Граф знаний (knowledge graph)
- **Модель-эталон:** Graphiti (эпизоды→сущности→рёбра-факты во времени) + Neo4j property-graph
  (типизированные узлы/рёбра, обход) + Logseq (граф из адресуемых блоков) + Juggl/Breadcrumbs
  (типизированные рёбра, иерархия up/down/same).
- **Проекция LifeOS:** уже есть `computeGraphProjection` (узлы=артефакты, рёбра с `reason` и теперь
  `since`). Достраиваем: типы рёбер, иерархию, темпоральную валидность/инвалидацию как **проекцию**
  над памятью, НЕ отдельную БД. Пакеты I/F7.

## 3. Поиск и retrieval
- **Модель-эталон:** гибрид — лексика (BM25/minisearch) + вектор (Smart Connections локальные
  эмбеддинги) + обход графа (Graphiti hybrid) с **fusion** и reranking (LlamaIndex node-postprocessors,
  Graphiti edge-distance). Честный лексический фоллбэк, если вектор недоступен.
- **Проекция LifeOS:** minisearch (есть) + опц. `@huggingface/transformers` + backlinks-обход →
  единый ретривер со слиянием сигналов и сниппетами. Пакеты R2/I5.

## 4. RAG / grounded answer
- **Модель-эталон:** Haystack (инспектируемый pipeline компонентов) + LlamaIndex (query-engine +
  response-synthesizer refine/compact) + NotebookLM (**grounding**: ответ только из источников +
  **честный отказ** + инлайн-цитаты на пассаж).
- **Проекция LifeOS:** «Спросить LifeOS» = запрос→retrieve артефактов→context→локальный ответ
  (Ollama-gated) с chunk-цитатами назад на артефакт; если контекста нет — честный отказ (§7). Пакет R1.

## 5. Агенты и оркестрация
- **Модель-эталон:** LangGraph — **граф состояний** (типизированное состояние, узлы=шаги, рёбра=переходы,
  conditional routing), **checkpointer** (состояние после каждого шага), **HITL-interrupt** (пауза→человек→resume),
  time-travel по чекпоинтам.
- **Проекция LifeOS:** «Сценарии»/Agent Center (срез 13) = состояние в IndexedDB (checkpoint через commit),
  шаги как proposals, пауза = подтверждение владельца (уже §7-паттерн). Пакет S.

## 6. Планирование и мутации
- **Модель-эталон:** LangGraph interrupts + человеческое подтверждение; всё значимое — через явный шаг.
- **Проекция LifeOS:** **уже канон** — proposal→preview→apply→receipt. Ни одной тихой мутации. Расширяем
  на все автодействия петли «разобрать день».

## 7. Синхронизация и хранение
- **Модель-эталон:** локальные инкрементальные индексы (Smart Connections re-index только правок),
  provenance-цепочки. Neo4j — merge-driver для параллельных правок (идея для будущего экспорта).
- **Проекция LifeOS:** IndexedDB + gzip-чанки (есть), `rebuildIndexes` инкрементно (есть), artifact-центрично.
  Local-first без сервера — **это преимущество**, которого нет у серверных доноров.

## 8. UI / визуальное мышление
- **Модель-эталон:** прогрессивное раскрытие (мало в главном меню); граф-canvas с фильтрами/минимапой
  (Juggl/Excalibrain focus-layout); пространственные карточки/кластеры (Heptabase); честные статусы
  провайдеров (NotebookLM).
- **Проекция LifeOS:** 9 пунктов главного меню + «Ещё»; canvas-граф (есть); будущий Whiteboard (V-слой).
  **Открытый долг (запрос владельца):** снизить перегруз панелей, ясно показывать «откуда что идёт».

## 9. Локальный AI
- **Модель-эталон:** Ollama-локально (Open WebUI/AnythingLLM UX), локальные эмбеддинги (Smart Connections),
  grounded + честный отказ (NotebookLM).
- **Проекция LifeOS:** Ollama-gated чат (есть), whisper.cpp STT (есть), локальные эмбеддинги опц.;
  провайдеры честны (not-connected/permission-required), никогда не имитируют успех.
