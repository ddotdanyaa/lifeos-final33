# MASTER_FEATURE_INDEX — приоритетные функции (решения к внедрению)

Главный рабочий индекс перед кодом. Здесь — **приоритетный набор** с полным набором полей
(Правило №8). **Полный каталог 160+ функций уже существует** в `docs/DONOR_FUNCTION_CATALOG.md`
(Правило №13 — не дублируем; для «длинного хвоста» смотреть туда). Статусы: 🔜 очередь · 🏗 в работе
· ✅ внедрено. Приоритет 1 = ближайшее.

Поля: **Проблема** (что у пользователя болит) · **Варианты** (реализации у доноров) ·
**Ограничения** · **Приоритет** · **Статус** · **Источник**.

### F-LOOP · Петля «разобрать день» (захват→обработка) — категория: Core Loop
- **Проблема:** накидал 10–20 голосовых/мыслей за день → к вечеру должны быть связи, инсайты, проекты; сейчас части не сшиты.
- **Варианты:** Mem0 (extract→link→score фактов) · Graphiti (эпизод→сущности→рёбра) · LangGraph (шаги-конвейер) · Cognee (ingest→cognify→search).
- **Ограничения:** без облака; все мутации через proposal→receipt (§7); лексический экстрактор вместо LLM по умолчанию.
- **Приоритет:** 1 · **Статус:** 🏗 (в работе, приоритет владельца №1) · **Источник:** Mem0, Graphiti, LangGraph, Cognee.
- **Дизайн LifeOS:** «Разобрать день» на Доме → собрать сегодняшние захваты → extractEntitiesFromText → кандидаты связей (proposal) → refreshDeterministicInsights → кластеры→проект (proposal) → дайджест «что понято за день».

### R1 · Спросить LifeOS (grounded answer + цитаты) — категория: RAG
- **Проблема:** нельзя спросить свою базу и получить ответ со ссылками на свои артефакты.
- **Варианты:** NotebookLM (grounding + честный отказ + инлайн-цитаты) · LlamaIndex (query-engine + response-synthesizer) · Haystack (компонентный pipeline).
- **Ограничения:** ответ только из артефактов; нет контекста → честный отказ (§7); Ollama-gated генерация.
- **Приоритет:** 2 · **Статус:** 🔜 (частично: цитаты C1.4 есть) · **Источник:** NotebookLM, LlamaIndex, Haystack.

### I5 · Семантические соседи «похоже по смыслу» — категория: Knowledge Graph
- **Проблема:** связанные мысли не находят друг друга без ручной вики-ссылки.
- **Варианты:** Smart Connections (локальные эмбеддинги + панель соседей) · Neo4j node-similarity (Jaccard/overlap) · KNN.
- **Ограничения:** эмбеддинги опц. (`@huggingface/transformers`), иначе лексический фоллбэк; приватно/локально.
- **Приоритет:** 3 · **Статус:** 🔜 · **Источник:** Smart Connections, Neo4j GDS.

### M1 · Скоринг важности + resurfacing — категория: Memory
- **Проблема:** важное тонет в потоке захватов; нет «наверх — главное».
- **Варианты:** Mem0 (importance = свежесть+частота+связность, decay) · SRS-идея (пора вернуться).
- **Ограничения:** decay — вес, не удаление; всё объяснимо (почему наверх).
- **Приоритет:** 3 · **Статус:** 🔜 · **Источник:** Mem0, Logseq flashcards.

### I (temporal) · Темпоральные рёбра графа — категория: Knowledge Graph
- **Проблема:** в графе не видно «откуда что идёт» и с какого момента связь.
- **Варианты:** Graphiti (bi-temporal, инвалидация, эпизоды-провенанс).
- **Ограничения:** проекция над памятью, НЕ Neo4j; инвалидация вместо delete.
- **Приоритет:** 2 · **Статус:** ✅ базово (рёбра несут `since` → инспектор «с DD.MM»); инвалидация/эпизоды 🔜 · **Источник:** Graphiti.

### Q1 · Запросы-как-представления — категория: Query & Views
- **Проблема:** один и тот же артефакт хочется видеть таблицей/списком/календарём по фильтру.
- **Варианты:** Dataview (TABLE/LIST/TASK/CALENDAR + WHERE/SORT/GROUP-BY) · Tana live-searches.
- **Ограничения:** без произвольного JS-рантайма (DataviewJS ⛔); декларативный фильтр.
- **Приоритет:** 4 · **Статус:** 🔜 (saved searches частично) · **Источник:** Dataview, Tana.

### S1 · Сценарии как граф состояний — категория: Agents
- **Проблема:** многошаговые автоматизации без прозрачного состояния и подтверждений.
- **Варианты:** LangGraph (state-graph + checkpointer + HITL-interrupt + conditional routing).
- **Ограничения:** checkpoint = commit; пауза = подтверждение владельца; без скрытых действий.
- **Приоритет:** 5 · **Статус:** 🔜 (Agent Center срез 13 — основа) · **Источник:** LangGraph.

### UX-debt · Разгрузка панелей / «откуда что идёт» — категория: UI
- **Проблема (запрос владельца):** много окон, вложенные стрелочки, кучно и непонятно, связи не читаются глазом.
- **Варианты:** прогрессивное раскрытие · focus-layout вокруг узла (Excalibrain) · авто-показ связей карточки (Heptabase) · честные статусы (NotebookLM).
- **Ограничения:** RU-first; 9 пунктов главного меню (канон nav); данные≠представление.
- **Приоритет:** 2 (владелец назвал) · **Статус:** 🔜 · **Источник:** Excalibrain, Heptabase, паттерн прогр. раскрытия.
