# MASTER_PROJECT_INDEX — реестр изученных проектов

Один источник правды по донорам. `Глубина`: **L** = лицензия+стек+назначение, **C** = ключевые
концепции/алгоритмы разобраны, **S** = построчный разбор конкретных модулей (по мере внедрения).
`Вердикт`: **код** = permissive+совместимый стек, можно брать код точечно; **идея** = только
концепции. Детали функций — `docs/DONOR_FUNCTION_CATALOG.md`. Лицензии — `docs/OSS_DONOR_AUDIT.md`.
