## Чего внешний текст НЕ знает про нас

1. **Уже измерено, что 96% контролов отвечают на нажатие.** Прибор пережил 9 собственных ошибок.
2. **Храповик:** число мёртвых не может вырасти незаметно — `npm run verify` краснеет.
3. **Эмбеддинги отключены осознанно**, с числом: разделение смысла и шума 0.027 на 10 фразах. Советовать «сделай semantic search» без этого числа — совет вслепую.
4. **45 донорских репозиториев распакованы**, 24 из них по лицензии допускают перенос кода. Советовать «изучи Mem0/Graphiti» — уже сделано.
5. **`app.js` = 709 функций, из них рендер только 49.** Оболочка — 7% кода. Поэтому «переписать с нуля» = переписать оболочку, не продукт.

## Что делать первым — по числам, а не по вкусу

**Развёрнутая версия с доказательствами по строкам кода — `docs/MVP_HARD_SPEC.md`.**
Там же 13 поправок к внешнему тексту, карта отказов, матрица решения типа, каталог из 13 типов
