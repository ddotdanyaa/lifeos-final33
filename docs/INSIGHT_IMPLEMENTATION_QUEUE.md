# INSIGHT IMPLEMENTATION QUEUE — конвейер по канону знаний/графа/памяти

Рабочий файл, чтобы не терять нить. Полная выгрузка функций доноров — `docs/DONOR_FUNCTION_CATALOG.md`
(160+ функций, §4 шаг 6). Принципы разбора — `docs/INSIGHT_ENGINE_CANON.md`.
Правила: пакетами 1-4 фичи, только принципы (не код доноров), через proposal/receipt где есть
мутация, гейты §4 CLAUDE.md на границе пакета, commit+push, отмечать `[x]` с датой.
Приоритет — по звёздам Canon §3, не по номеру пакета.

Легенда донора в скобках. Каждый пакет = один реализуемый принцип из каталога.

## ЗНАНИЯ / ГРАФ / ИНСАЙТЫ (I)

- [x] I0 (2026-07-29, донор не нужен — боль владельца дословно) **Инсайт = вывод, а не число.**
  Владелец: «Блок называется Инсайты, но инсайтов нет. Инсайт — это не связь, инсайт — это вывод».
  `core/owner-themes.mjs`: «Ты возвращаешься к этому 3-й день» (тема в записях ≥3 РАЗНЫХ дней за
  неделю, основа слова в 5 знаков) и «Сегодня ты думаешь об одном» (≥3 записей И половина дня).
  Считается по словам ВЛАДЕЛЬЦА: документация LifeOS о себе и заметки `origin: "system"`
  исключены — иначе первый вывод звучал «Сегодня ты думаешь об одном: LifeOS Product Brain».
  Каждый вывод объясняет себя (`detail`) и ссылается на записи (`refs`). Идут ПЕРВЫМИ в списке:
  вывод о мышлении важнее, чем «частый расход: такси». Гейт: `insights-are-conclusions.spec.mjs`
  (3/3), третья спека ловит ЛОЖНЫЙ вывод.

- [ ] I12 (донор: Neo4j link-prediction Adamic-Adar/common-neighbors) Усилить ранжирование кандидатов

- [ ] I13 (донор: Breadcrumbs hierarchy up/down/same) Иерархические связи артефактов

- [ ] I14 (донор: Smart Connections random-connection) «🎲 неожиданная связь»: кнопка прыжка к

## ПАМЯТЬ (M)

- [ ] M1 (донор: Mem0 importance-scoring + forgetting/decay) Скоринг важности артефакта
  (свежесть + частота обращений + связность) с decay-весом и resurfacing «пора вспомнить давнее».
  Честная арифметика, старое не удаляется — гаснет в ранге.
- [ ] M2 (доноры: Zep summary-over-time + Mem0 multi-level memory) Сводка чата по времени +
  «факты из разговоров» → предложения в память (через proposal). Память user/session/agent.
- [ ] M3 (доноры: NotebookLM flashcards + Logseq SRS) Карточки/повторение из артефактов →
  resurfacing «пора повторить» поверх скоринга M1.
- [ ] M4 (донор: Graphiti bi-temporal + fact-invalidation; Mem0 conflict-resolution) Версии факта
  во времени: обновление артефакта помечает старую версию superseded (не удаляет), «что было
  истинно на дату T». Через proposal.
