## 2. Главный вопрос: «Открыл LifeOS — что делаю? 1-2-3-4?»

**Сейчас ответа НЕТ.** На Доме 22 кнопки, 7 секций, 140 слов, и ни один элемент не говорит «начни
отсюда». Композитор (ввод) конкурирует с 3 мини-карточками, «LifeOS понял», утренней сводкой и
«Мой день». Capture-first размыт.

**Предлагаемый явный сценарий Дома (1-2-3-4):**
1. **Записать** — одно поле, одно действие «Разобрать» (задача/расход/мысль/голос). Всё остальное — потом.
2. **Что сегодня** — следующее действие + деньги за день (одна строка, не 3 карточки).
3. **Разобрать входящее** — очередь/предложения, если накопилось (иначе скрыто).
4. Дальше растёт по данным (утро/инсайты/день) — прогрессивно, а не всё сразу.

## 3. Проблемы, приоритизированные (⭐⭐⭐⭐⭐ обязательно → ⭐ не сейчас)

- ⭐⭐⭐⭐⭐ **3 экрана переполняются по горизонтали** (Сегодня, Контроль, Сценарии) — реальные баги адаптива. Чинить в D0/по экранам.
- ⭐⭐⭐⭐⭐ **Дом = 22 кнопки**, нет «1-2-3-4». Главный экран не ведёт. Основной таргет редизайна D1.
- ⭐⭐⭐⭐⭐ **Контроль (521 слово/18 секций) и Подключения (520/18)** — стены-кокпиты. Свернуть в аккордеоны/вкладки, показывать по запросу.
- ⭐⭐⭐⭐ **Цели и Привычки — идентичны** (3/5/4/13/156) = один экран под двумя пунктами меню. Объединить в «Цели и привычки», убрать дубль-пункт.
- ⭐⭐⭐⭐ **Лента — 31 секция**, самый «дроблёный» экран. Проверить группировку/виртуализацию (см. shadcn-table).
- ⭐⭐⭐⭐ **База 31 кнопка, Паки 32 кнопки** — списки без тулбара/массовых действий; каждая строка тащит 3-4 кнопки. Паттерн shadcn-table: выбор строк → плавающая панель действий.
- ⭐⭐⭐ **10 из 26 экранов (38%) — черновики** 🚧. Уже помечены и сгруппированы; на этапе «скрыть незавершённое» — убрать из основного меню под «Показать всё».
- ⭐⭐⭐ **Дублирование верхней панели**: «Ввод» и «Контроль» в шапке дублируют пункты навигации.
- ⭐⭐ **Конструктор — 17 полей** на экране: форма-монстр. Разбить на шаги (multi-step, см. dashboard-starter).

## 4. Что конкретно: удалить / объединить / починить

**Объединить:**
- Цели + Привычки → один экран (−1 пункт меню).
- 3 мини-карточки Дома (Сегодня/Деньги/Привычки) → одна строка-сводка.

**Убрать/свернуть:**
- Контроль и Подключения: 18 секций → 4-5 сворачиваемых групп, открытые по запросу.
- Дашборд-виджеты Дома: контролы ↑↓/Скрыть у каждого виджета (это +3 кнопки на виджет = большая доля из 22) — убрать в режим «настроить», а не постоянно.

**Починить (адаптив):**
- Сегодня — правая колонка (Привычки/Напоминания/План) уезжает за край → grid на `minmax()`/wrap.
- Контроль, Сценарии — overflow контейнеров.

## 6. Вывод для последовательности

Аудит подтверждает: **UX-проблемы структурные, не косметические** — нет ведущего сценария, стены-кокпиты,
дубли, 3 overflow. Значит редизайн (D0→экраны) должен их закрывать адресно, а не просто «покрасить».
Дальнейшее изучение репо 2-5 веду ПОД эти проблемы: precedent (структура/навигация SaaS) и
dashboard-starter (свернуть кокпиты, multi-step формы) — прицельно под Контроль/Подключения/Конструктор;
shadcn-table — под Базу/Паки/Ленту; magicui — сдержанные переходы в самом конце.
