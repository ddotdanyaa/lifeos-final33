## Порядок при возобновлении

1. `node tools/audit-liveness-gate.mjs` — узнать планку.
2. `git worktree list`; по каждой незавершённой: `git -C .claude/worktrees/agent-<id> diff --stat`.
3. Патч: `git -C <worktree> diff -- app.js ui core > .claude/patches/<id>.patch`, применять
   `patch -p1 --fuzz=5`; новые файлы копировать руками.
4. После каждого слияния: `npm run verify` + `node tools/audit-liveness.mjs <экраны>`.
5. Красный храповик НЕ обходить.
