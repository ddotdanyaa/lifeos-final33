## 2. Единица работы — вертикальный срез

Правило внешнего текста принимается целиком и становится законом проекта:

> **Новая функция не начинается, пока предыдущий сценарий не проходится посторонним человеком
> без объяснений.** Если сценарий требует инструкции — он не завершён.

Срез считается закрытым, когда выполнены **все пять** условий:

1. Сценарий проходится от начала до конца в браузере на `127.0.0.1:4173`.
2. Спека сценария зелёная (`output/playwright/<slice>.spec.mjs`).
3. `npm run verify` зелёный, `node tools/audit-liveness-gate.mjs` не поднял планку мёртвых.
4. Каждый новый контрол имеет `data-testid` и отвечает на нажатие (иначе он мёртвый по прибору).
5. В `docs/IMPROVEMENT_LEDGER.md` записан receipt: что изменилось словами владельца.

## 3. Десять сценариев — контракт каждого

Формат один: **боль → что видно → что внутри (имена из кода) → состояния → приёмка → негатив.**

### С1. Быстро сохранить мысль · готовность 45 %

- **Видно:** одно поле, одна главная кнопка, скрепка, микрофон. Больше на экране нет ничего.
- **Внутри:** `renderAssistantInput` (`ui/components/AssistantInput.js:64`) → `capture-text` →
  `analyzeArtifactInput` (`app.js:5148`).
- **Состояния черновика:** `пусто → печатается → сохранён-локально → разбирается → разобран`.
  Черновик живёт в `state.captureDraft`; закрытие вкладки его не теряет.
- **Приёмка:** в разметке композера **ровно три** элемента с `data-action`, кроме главной кнопки.
  Спека считает их и падает на четвёртом.
- **Негатив:** пустое поле + прикреплённый файл → кнопка называет «Разобрать прикреплённое (N)»
  (уже реализовано, `AssistantInput.js:97`), а не молчит.

### С2. Понять, что понял ИИ · готовность 30 % — **главный разрыв MVP**

- **Видно:** список выводов, **каждый отдельной строкой**, у каждого — цитата из записи,
  свой уровень доверия словами и **свои** кнопки. Не более 7 строк; остальное под «ещё N».
- **Внутри:** данные уже есть: `proposal.quote` (`app.js:6115`), `proposal.reason`,
  `proposal.confidence`, `buildHumanCaptureAnswer` (`app.js:18912`).
- **Приёмка:** спека находит ≥ 3 вывода, у каждого непустой источник и **собственная** кнопка.
  Кнопки «Принять всё» на первом экране **нет**.
- **Негатив:** разбор дал 0 выводов → строка «Я не понял из этого ничего конкретного» + кнопка
  «Сохранить как есть». Никогда не молчание.
- **Запрещено:** восстанавливать `renderProposalPanelV2` — она вызывает несуществующие функции
  (поправка №8).

### С3. Увидеть старые мысли · готовность 70 %

- **Есть:** `core/similar-thoughts.mjs` (Дайс + Джаро-Винклер, донор `natural`, MIT), показ под
  полем во время набора — `AssistantInput.js:11–26`, с датой и вердиктом.
- **Нет:** кнопки вердикта. Тип предложения `supersede` в движке уже есть (`app.js:7922`,
  `app.js:10257`) и никем со стороны похожих мыслей не создаётся.
- **Приёмка:** «уточнение» помечает прежнюю запись заменённой (одна запись, не две) и пишет
  решение в `state.decisions`.

### С4. Почему появился инсайт · готовность 55 %

- **Есть:** `computeInsights` `app.js:18414`, источники `refs`/`members` кликабельны,
  числа уверенности наружу не выходят (`ui/home.js:156–160` вырезает «сила связи 0,67»).
- **Нет:** «почему **именно сейчас**» и словесного уровня доверия из журнала.
- **Приёмка:** у каждого инсайта раскрывается «Почему» с датами опорных записей и фразой
  «это уже N-й раз за M дней».

### С5. Система учится · готовность 75 % (не 25 %)

- **Есть, целиком:** журнал (`recordOwnerDecision`), ретро-заполнение, затухание, дрейф,
  профиль владельца, впрыск в ранжирование, панель в Контроле (`ui/control.js:338`).
- **Нет ровно трёх проводов:** (а) `calibratedConfidence` не вызывается; (б) `freezeCanary`
  не вызывается; (в) нет экрана «что изменилось сегодня».
- **Приёмка:** после 8 решений одного типа в интерфейсе рядом с предложением стоит
  «по твоим решениям — берёшь 6 из 8», а не «уверенность 72 %». До 8 — «мало данных: 3 из 8».

### С6. Память находит без поиска · готовность 45 %

- **Есть:** Fuse.js (Apache-2.0, вендорен), `core/owner-search.mjs`, дедуп выдачи.
- **Осознанно нет:** эмбеддингов — измеренный разрыв 0.027, порога не существует.
- **Решение для MVP:** не строить семантику. Строить **возврат к источнику**: любой ответ
  показывает дату + кнопку «открыть запись». Это закрывает боль на 80 % от стоимости 5 %.

### С7. Видеть знания, а не граф · готовность 35 %

- **Приёмка (Т6):** на карточке записи спека не находит слов `ID`, `Type`, `Owner`, `контракт`,
  `метод`, `рендер`. Сейчас `looksTechnical` гасит их частично — этого мало.

### С8. Вечером закрыть день · готовность 30 %

- **Есть:** `computeDayDigestView` `app.js:15963`, `renderDayDigest`.
- **Нет:** «перенести на завтра» — открытые петли не переезжают.

### С9. Система спорит · готовность 20 %

- **Есть:** `computeGoalForecast` `app.js:17684`, `computeContradictions` `app.js:17583`.
- **Нет:** подачи как возражения владельцу. **Вне MVP** — сценарий не блокирует тестирование.

### С10. Не сортировать вручную · готовность 50 %

- Разбор тип определяет сам; UI всё равно спрашивает кнопками. Закрывается вместе с С1.

## 6. Сигналы обучения и их веса

Веса не выдуманы — они уже заданы в коде, здесь только сведены в одно место.

| Сигнал | Вес | Откуда |
|---|---|---|
| Принял молча | 1.0, `decision=applied` | `app.js:8210` |
| Принял с правкой текста | 1.0 + флаг `edited` («поняли наполовину») | `app.js:8226`, вычисление `app.js:8117` |
| Отклонил | 1.0, `decision=dismissed` | `app.js:8782` |
| Восстановлено из аудита (ретро) | **0.5** | `app.js:8230` |
| Решение возрастом D дней | `0.5^(D/60)` | `decisionWeight` `app.js:8296` |
| Канареечное решение | **0** — в обучение не входит никогда | `app.js:8305` |
| Ставка без ответа | `unverifiable`, из веса **исключается** | `app.js:8635` |

**Пороги:** доверять типу с 8 решений (`MIN_DECISIONS_FOR_TRUST`); дрейф — падение доли принятых
на 0.25 на окне 20 (`DRIFT_WINDOW`, `DRIFT_DROP`); канарейка — 50 решений, падение 0.15.

**Что не меняется автоматически никогда** (инвариант И-2, `app.js:8199`): журнал — это **память**,
а не политика. Он копит доказательства; веса и правила меняет только отдельная явная операция.
Профиль владельца **не создаёт объектов, не меняет типы и не отменяет правила** — только понижает
уверенность и добавляет причину словами (`app.js:8572–8575`).

## 7. Карта отказов

| Отказ | Что видит владелец | Что сохраняется | Как выйти |
|---|---|---|---|
| Голос не расшифровался | «Расшифровка не получилась. Аудио сохранено, текст можно вписать руками» | сам файл + запись | кнопка «Вписать текст» |
| Разбор дал 0 выводов | «Я не понял из этого ничего конкретного» | сырой текст | «Сохранить как есть» |
| Найдено ≥ 10 похожих | показываются 3 + «ещё 7» | всё | вердикт по каждой |
| Уверенность < 40 % | формулировка «предположение», а не утверждение | предложение открыто | ручной выбор |
| Провайдер недоступен | `not-connected` / `provider_unavailable` дословно | ничего не теряется | одна кнопка «подключить» |
| Обработка > 10 с | видимый индикатор + что именно делается | черновик | «Отменить» |
| Разбор упал с ошибкой | что случилось и что нажать | черновик и файл | повтор |
| Владелец передумал в момент разбора | ничего не записано без подтверждения | черновик | «Очистить» |

**Закон:** имитация успеха запрещена (CLAUDE.md §7). `not-connected` пишется как есть.

## 8. Правила доверия — четыре уровня и обязанность молчать

| Уровень | Формулировка на экране | Условие |
|---|---|---|
| По решениям | «по твоим решениям — берёшь 6 из 8» | `trusted === true` в `computeCalibration` |
| Заявлено | «предварительно» | решений < 8 |
| Мало данных | «мало данных: 3 из 8» | так и написано, числа нет |
| Заморожено | «обучение остановлено: точность упала» | канарейка `frozenLearning` |

Система **обязана** сказать «не знаю», когда: решений по типу < 8; дрейф обнаружен; дата не
распознана (тогда — догадка, помеченная догадкой, — правило владельца от 2026-07-30, никогда
пустое поле); похожесть между 0.4 и 0.6 (зона, где ни дубль, ни новое).

## 12. Антипаттерны — что запрещено делать в этих срезах

1. Возвращать к жизни `renderProposalPanelV2` — она вызывает несуществующие функции.

5. Учить систему на канареечных решениях.
6. Считать молчание владельца отказом (`unverifiable ≠ miss`).
7. Заводить новый экран под то, что помещается в существующий (инвариант И-7).
8. Инсайт без опорных записей, без даты и без действия.

12. Новая зависимость без решения владельца.

## 13. Очередь до старта тестирования

Порядок выведен из разрыва «важность минус готовность», а не из вкуса.

| Срез | Что делает | Стоимость | Закрывает |
|---|---|---|---|
| **А** | Провод `calibratedConfidence` в отображение предложения + строка «мало данных: N из 8» | ~40 строк | С5, Т5 частично |
| **Б** | Построчный разбор на Доме: строка = вывод + цитата + свои кнопки. «Принять всё» уезжает вниз | новый компонент в `ui/` | С2, Т5 — **главный разрыв** |
| **В** | Кнопка вердикта «дубль · уточнение · новое» под похожими; «уточнение» → `supersede` | ~60 строк | С3, Т7 |
| **Г** | Композер 10 → 3 кнопки; три спеки переписываются вместе с продуктом по Т1 | правка + 3 спеки | С1, С10, Т1 |
| **Д** | Автозаморозка канарейки при 50 решениях + экран «чему система научилась за сегодня» | ~80 строк | С5 до конца, дыра №5 и №6 внешнего текста |

Срезы А–В снимают блокировку ежедневного использования: владелец кидает мысль, видит построчный
разбор с источниками, выносит вердикт по похожим, и следующее предложение приходит с числом,
полученным из его собственных решений. Г — самая громкая претензия из четырнадцати. Д — слой
доверия, без которого через неделю накопится мусор, который нечем откатить.

## 14. Визуальная директива экрана «Дом»

Переделывается **один экран**, движок не трогается (`MVP_SPEC.md` §5). Токены берутся из
`styles.css`, новых не заводится.

**Палитра (существующая, V3):** `--paper #f7f7f9` · `--surface #ffffff` · `--ink #0c0c0f` ·
`--muted #6b6b74` · `--accent #8A6316` (латунь, контраст к бумаге посчитан 5.42 / к чернилам 7.93) ·
`--line rgba(12,12,15,.1)` — волосяная граница вместо сплошной серой рамки.

**Иерархия — ровно три уровня, сверху вниз:**

```
┌─────────────────────────────────────────────┐
│  Что добавить в LifeOS?                     │   ← поле, ничего вокруг
│  [                                       ]  │
│  📎  🎙                        [ Разобрать ]│   ← три контрола, не десять
├─────────────────────────────────────────────┤
│  Похоже, ты уже об этом писал — 2           │   ← во время набора
│  · Прогноз финансов   15.07   [дубль][уточнение][новое]
├─────────────────────────────────────────────┤
│  Я понял из этой записи                     │
│  ├ Идея проекта «месячный прогноз»          │
│  │ «…хочу видеть на месяц вперёд…»          │   ← цитата = основание
│  │ предварительно            [Создать][Не то]│
│  ├ Задача: найти репозитории под финансы    │
│  │ «…найти несколько подходящих…»           │
│  │ по твоим решениям — берёшь 6 из 8  [Создать][Не то]
│  └ ещё 3 вывода                             │
│                              Принять всё ▸  │   ← внизу, тихо
└─────────────────────────────────────────────┘
```

**Подпись экрана — «полоса основания».** Слева у каждого вывода вертикальная волосяная линия
цвета `--line`, переходящая в цитату. Это единственный декоративный элемент, и он несёт смысл:
вывод физически растёт из куска записи. Убрать линию — потерять Т5. Больше на экране не
акцентируется ничего: латунь — только на главной кнопке и на активном вердикте.

**Типографика:** заголовок вывода `--text-base` полужирный (`--ink`), цитата `--text-sm` курсивом
(`--muted`), уровень доверия `--text-xs` (`--muted`). Число уверенности **не печатается никогда** —
только словами (правило `ui/home.js:156`).

**Движение:** одна оркестрованная последовательность на весь экран — выводы появляются сверху вниз
со сдвигом 40 мс через `--ease`. Ничего больше не анимируется. `prefers-reduced-motion` уважается.

**Что вырезано сознательно:** аккордеоны, вкладки, бейджи количества, иконки у каждой строки,
прогресс-кольца. Первый экран остаётся спокойным и capture-first (CLAUDE.md §6).
