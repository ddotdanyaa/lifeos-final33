# LESSONS — инженерные уроки LifeOS (переиспользуемые паттерны)

Правило файла: сюда попадают только уроки, которые СЭКОНОМЯТ ЧАСЫ будущему исполнителю.
Один урок = заголовок + суть + где это уже стреляло. Полные расследования — в DECISIONS.md.

## CSS: звёздочка+слэш внутри комментария закрывает его досрочно
Последовательность `*` + `/` без пробела — это токен конца комментария ВЕЗДЕ, даже в прозе
и «внутри кавычек». Парсер восстанавливается, съедая следующее объявление. Стреляло дважды
(U0 и V0.5): `--text-xs` и целый блок `:root` тихо не применялись сессиями. Проверка:
диагностика через `document.styleSheets` (CSSOM), не через чтение файла глазами.

## normalizeState: новые поля — в ДВЕ точки
`commit()` рендерит ДО повторного прогона normalizeState. Новое поле состояния обязано
задаваться и в `createInitialState` (литерал), и в normalize-ветке; новые поля объектов —
в месте создания И в normalize-цикле. Иначе «поле есть, но undefined до перезагрузки».

## Браузерный ESM: bare-specifier внутри чужого ESM ломает динамический import()
chart.js `dist/chart.js` тянет `@kurkle/color` bare-импортом — в браузере без бандлера это
фатально. Решение: UMD-сборка через классический `<script>` + `window.*` глобал. Проверять
ЛЮБУЮ новую библиотеку на этот паттерн ДО интеграции.

## Service worker: кэш переживает деплой и владелец видит «старую версию»
Стреляло по-настоящему: протухший CSS из кэша во время редизайна. Решение навсегда:
`npm run stamp` — git-hash в шапке UI (`build-version`) + hash в имени SW-кэша. Первый
вопрос при «я не вижу изменений» — сверить хеш в шапке с последним коммитом.

## E2E: параллельный полный прогон душит тесты с реальной сетью/моделью
Реальные загрузки моделей и CPU-генерация Ollama не укладываются в таймауты под
`--workers=2` (задокументировано трижды: whisper download, vosk percent, ollama chat).
Красный такой тест = сперва перепрогнать изолированно `--workers=1`, потом делать выводы.
Отдельно: осиротевшие `chrome-headless-shell.exe` от прерванных прогонов душат
requestAnimationFrame у НЕ связанных тестов — убивать перед диагностикой «регрессии».

## app.js: мёртвый инлайн-рендер ≠ живой UI
В app.js есть большие недостижимые render-функции старой оболочки. ЛЮБАЯ правка UI
проверяется против живого пути `ui/*.js` + `renderNewShell`, никогда — по факту «нашёл
функцию с похожим названием в app.js».

## Полный прогон на границе среза ловит то, что целевые спеки не видят
Регрессия U4 (кнопка стала недостижимой + потерянное поле mutationMode) жила незамеченной,
пока по-пакетно гонялись только целевые спеки. Полный набор — обязателен на границе, но
именно там (диета процесса), не после каждого файла.

## Секвенс полного re-render: <audio>/canvas умирают на каждом commit()
`render()` пересоздаёт DOM целиком — непрерывное сохранение позиции аудио через timeupdate
рвало бы воспроизведение 4 раза в секунду. Паттерн: сохранять на редких реальных событиях
(pause), восстанавливать в mount-функции (mountAudioPlayer / mountFinanceChart-стиль).

## Helper из ui/ не виден в app.js — тихий ReferenceError глотается .catch()
`plural` живёт в `ui/components/shared.js`; вызов его из `app.js` бросает ReferenceError,
который `handleAction(...).catch()` проглатывает — фича «молча не работает» без ошибки в
консоли. Стреляло в срезе 5 (чат переставал отвечать вообще). Правило: код в app.js
использует только то, что определено в app.js; общий helper — дублировать локально
(`pluralRu`) или искать существующий аналог. Диагностика: `get_page_text`/console показали
error boundary, хотя `--check` и smoke были зелёные.

## Внешний движок = отдельный процесс поверх HTTP, не встраивание
whisper.cpp и Ollama живут как локальные даемоны, которые владелец запускает сам; апп
только probes/calls с честными статусами. Это же — шаблон для любого будущего тяжёлого
движка: не тащить в браузер то, что стабильнее живёт процессом рядом.
