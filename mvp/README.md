# LifeOS MVP

Чистая сборка с нуля. Ноль строк из старого проекта.

## Запуск

```
node mvp/server.mjs        # http://127.0.0.1:4180
```

Ничего не собирается, зависимостей нет. Браузер грузит модули напрямую.

## Что уже работает (проверено сквозной спекой, 8/8)

| Сценарий | Что делает |
|---|---|
| S1 | Пишешь как есть — тип определяется сам, выбора типа на экране нет вовсе |
| S1 | Черновик переживает перезагрузку и закрытие вкладки |
| S2 | Каждый вывод отдельно: своя цитата, своя уверенность, свои три кнопки. Кнопки «принять всё» нет |
| S2 | Ниже порога 0.75 система СПРАШИВАЕТ, а не решает за тебя |
| S3 | Похожее прошлое показывается ДО сохранения, а не после |
| S4 | У вывода видны записи с датами, до них можно дойти |
| S4 | Вывод можно отклонить, и он не возвращается после перезагрузки |
| S5 | Пять правок одного типа — и следующий вывод приходит с учтённым весом. Видно на экране |

## Проверка

```
npx playwright test mvp/mvp.spec.mjs --workers=1
```

Все проверки идут через ВИДИМОЕ на экране. Чтение внутреннего состояния прошло бы и при
полностью сломанном интерфейсе — такие проверки здесь не считаются.

## Устройство

```
core/text.js       основы слов, кириллические границы, даты
core/db.js         IndexedDB; пустое поверх непустого не пишется никогда
core/analyze.js    текст → выводы с цитатой и уверенностью
core/insights.js   выводы из НЕСКОЛЬКИХ записей разных дней
core/learn.js      правка → сигнал → вес → следующий разбор
ui/views.js        разметка
app.js             события и отрисовка
```

Правило файла: 500 строк потолок. Сейчас всё вместе — 823 строки.

## Границы обучения

Шаг веса 0.03, коридор [0.5, 1.4], применяется с пятого сигнала по типу. Обучение меняет
ТОЛЬКО уверенность и порядок — оно не создаёт, не правит и не удаляет ни одной твоей записи.
