## Как запустить

```
npm start          # http://localhost:4173
npm run verify     # node --check + smoke (86 маркеров)
npm run stamp      # прошить git-hash в шапку UI + имя SW-кэша (перед каждым коммитом)
```

**Проверка «на что я смотрю»**: в правом верхнем углу шапки приложения виден хеш сборки
(`data-testid="build-version"`). Если он НЕ равен последнему коммиту (`git log --oneline -1`)
— ты смотришь на закэшированную старую версию: обнови страницу (Ctrl+Shift+R); новая
сборка сама инвалидирует старый service-worker-кэш при активации.

**Срез 7.5 — честная доводка графа после реакции владельца (2026-07-20):** владелец
сравнил со скриншотами Obsidian — реальный граф был «клубком». Три причины (честно): (1)
объём данных — в Obsidian-картинках зрелые хранилища на сотни-тысячи заметок, у владельца
~15-35 артефактов (это данные, не код); (2) на канвас валилась ВНУТРЕННЯЯ машинерия
(provider-run «ollama probe», flow-run «pxa boot», предложения, чат-логи) — теперь
`graphForDisplay` прячет их (`GRAPH_DISPLAY_HIDDEN_TYPES`), граф показывает только жизненные
артефакты (как Obsidian показывает заметки, а не логи); (3) стиль — узлы уменьшены (5+val*0.6,
cap 16), связи тоньше и бледнее (0.9px, ярко только у окрестности), цвета приглушены,
подписи реже/мельче (11px, только хабы deg≥4/выбранный/наведённый); раскладка шире
(репульсия 8600, стартовый радиус 130-430). Verified: H07, product-map-graph, kb-smoke,
product-brain зелёные; счётчик графа не ассертится порогом, фильтр безопасен. Скриншоты
`graph-refined-*.png`. Остаётся честный разрыв с Obsidian по «галактике» — это объём
хранилища, наполнится с использованием.
