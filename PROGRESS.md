# LifeOS — PROGRESS (леджер срезов плана v1.4)

План и скоуп: [docs/LIFEOS_V1_4_FULL_BUILD_PLAN.md](docs/LIFEOS_V1_4_FULL_BUILD_PLAN.md).
История до v1.4 (v1.0 → v1.1 → v1.2 → v1.3, ~65 коммитов, все пакеты и решения) — в
леджерах соответствующих планов в `docs/` и в DECISIONS.md; этот файл начат заново
2026-07-20 как единственный живой леджер по правилу владельца: «после каждого среза —
commit + push + PROGRESS.md + инструкция как проверить за 60 секунд».

## Как запустить

```
npm start          # http://localhost:4173
npm run verify     # node --check + smoke (86 маркеров)
npm run stamp      # прошить git-hash в шапку UI + имя SW-кэша (перед каждым коммитом)
```

**Проверка «на что я смотрю»**: в правом верхнем углу шапки приложения виден хеш сборки
(`data-testid="build-version"`). Если он НЕ равен последнему коммиту (`git log --oneline -1`)
— ты смотришь на закэшированную старую версию: обнови страницу (Ctrl+Shift+R); новая
сборка сама инвалидирует старый service-worker-кэш при активации.

### ✅ Срез 2 — Artifact Core + текстовый capture (2026-07-20)

- Категории: Architecture, Discovery-free. Зависит от: среза 1.
- Происхождение артефакта (`source.origin`: text/voice/file) + неизменяемый снимок
  исходного ввода (`source.originalText` — парсеры дополняют `text`, но что реально вошло,
  сохранено навсегда). Люди-сущности (`entities.people`, эвристика заглавных слов не в
  начале предложения + стоп-лист) — видны в карточке «LifeOS понял» строкой «Люди: …».
- **Проверить за 60 секунд**: введи на Дом «Обсудить с Женей ремонт машины» → Разобрать →
  в карточке разбора появится «Люди: Женей».
- Долг: entity resolution (Женей=Женя=Жека) — срез 10; места-сущности — вместе с ним.

### ✅ Срез 3 — Финансы + такси + проекции (2026-07-20)

- Категории: Feature (ежедневный цикл владельца). Зависит от: среза 2, U2-парсера.
- Смена одной фразой: «Отработал 12 часов, заработал 8700, бензин 1900» → предпросмотр
  разбора (часы/доход/расходы) в карточке «LifeOS понял» → «Записать смену» одним нажатием
  → доход 8700 с часами, расход «Бензин 1900», блок «Смена 12 ч» в календаре. Правила/regex
  (`parseShiftEntry`), LLM не в критическом пути. Часы живут на доходной транзакции
  (`shiftHours`) — не отдельная коллекция (SSoT).
- Недельный виджет в Деньгах: Часы, Доход/час, редактируемая «Цель недели», «До цели: X».
- Verified: `shift-week-cycle.spec.mjs` (2/2 с первого прогона) + 14 регрессий
  (chat-actions, money-fast, ai-memory-gate, quick-actions, H01-H10) + все аудиты + smoke.
- **Проверить за 60 секунд**: на Дом введи «Отработал 12 часов, заработал 8700, бензин
  1900» → увидишь разбор → «Записать смену» → открой Деньги: в «Неделе» часы 12 ч,
  доход/час 725 ₽, поставь цель 30000 → «До цели: 21 300 ₽».
- Долг: прогноз/кэш-флоу и отчёты через чат — срезы 5 и 11.
### ✅ Срез 4 — Дашборд + утренняя сводка (2026-07-20)

- Категории: Feature (видимая, первый экран). Зависит от: срезов 2, 3.
- Утренняя сводка — первый блок на Доме (`renderMorningSummary`, `morningSummary(state)` в
  app.js). Только реальные данные: дата + день недели по-русски, прогресс к недельной цели
  (из среза 3), задачи на сегодня с названиями, итоги вчера (выполнено/заработано/потрачено).
  Пустое состояние честное («цель не задана», «задач нет», «вчера записей не было»).
- Побочный фикс (видимая шероховатость, найдена на скриншоте): фраза смены со словом «обед»
  триггерила лишнюю задачу с кривым названием — подавлено, когда ввод распознан как смена.
- Verified: `morning-summary.spec.mjs` 1/1 первым прогоном; срезы 2/3 + money-fast + H01-H10
  + quick-actions + chat-actions зелёные; аудиты/smoke/build-public. Скриншоты light+dark в
  `docs/qc/screens/slice4/`.
- **Проверить за 60 секунд**: открой Дом → вверху «Доброе утро» с датой и честной сводкой.
  Запиши смену (срез 3), поставь цель недели в Деньгах → вернись на Дом → «До недельной
  цели» показывает реальный остаток.

### ✅ Срез 5 — Чат на реальных данных (разморозка WIP) (2026-07-20)

- Категории: Feature (главный интерфейс). Зависит от: срезов 3, 4; V1 WIP (разморожен).
- Чат отвечает на вопросы про деньги/смены/совет ТОЛЬКО из реальных артефактов, без Ollama
  (`chatMoneyDataAnswer` в app.js — регекс + агрегация транзакций). «Сколько заработал за
  неделю?» → сумма доходов + остаток до цели; «Какая последняя смена?» → дата/часы/доход/
  ставка; «Стоит ли работать?» → совет от цели и темпа с обоснованием. Цифры детерминированы
  (не отдаются модели на выдумывание) даже когда Ollama доступна. Ollama-путь (V1 CHAT_BRAIN:
  RU-промпт с граф/днём-контекстом) остаётся для свободных вопросов.
- Чистка мусора в глазах (по прямой просьбе владельца): убраны технические строки
  `receipt receipt_xxx` из пузырей чата; кнопка «Сделать задачей» больше не висит под
  вопросами (только под утверждениями).
- Побочный фикс: `pluralRu` в app.js (ui-шный `plural` там недоступен, вызывал тихую
  ошибку → чат не отвечал вообще; поймано браузерной диагностикой).
- Verified: `chat-real-data.spec.mjs` (без Ollama, детерминированный) + chat-actions +
  ai-memory-gate + chat-thread-search + market-owner + owner-rescue + H01-H10 зелёные.
  Скриншоты light+dark в `docs/qc/screens/slice5/`.
- **Проверить за 60 секунд**: запиши 1-2 смены (срез 3), поставь цель недели (Деньги),
  открой Чат → спроси «Сколько я заработал за неделю?» и «Стоит ли завтра работать?» —
  увидишь реальные цифры и обоснованный совет.
- Долг: живой Ollama-гейт (`chat-brain-graph-context.spec.mjs`) — при стабильной среде
  (реальная CPU-генерация флейкует под нагрузкой, см. LESSONS.md); отчёты за месяц/периоды —
  срез 11.

**Срез 5.5 — редизайн чата в стиле ChatGPT/Claude (2026-07-20, frontend-design pass):**

### ✅ Срез 6 — Whisper + голосовой пайплайн (2026-07-20)

- Категории: Feature (голос как первоклассный вход). Зависит от: срезов 2, 3, 5, 5.5; U3.
- whisper.cpp расшифровка уже работала (U3). Добрано: расшифровка (голос ИЛИ ручная)
  проходит ТОТ ЖЕ разбор, что и печатный ввод — `saveSourceTranscript` теперь кладёт
  расшифровку сообщением владельца в чат и создаёт типизированное предложение через
  `createChatMessageProposal`. Надиктованное «отработал 12 часов заработал 8700 бензин 1900»
  → предложение-СМЕНА в чистом чате (срез 5.5) → «Записать смену» одним нажатием → реальные
  доход+часы+расход. Люди-сущности из расшифровки тоже извлекаются (срез 2). `directTypes`
  получил "shift" — надиктованная смена больше не порождает мусорные «разобрать/задачи».
- Verified: `voice-shift-pipeline.spec.mjs` (детерминированный, без демона — ручная
  расшифровка = тот же путь; реальный голос через whisper.cpp — `voice-loop-whispercpp`,
  нужен демон) 1/1 первым прогоном; shift-week + chat-actions + chat-real-data + H01-H10 +
  whisper honest gate + waveform (изолированно) зелёные.
- **Проверить за 60 секунд**: Плеер → добавь аудио → в «Ручная расшифровка» впиши
  «Отработал 12 часов, заработал 8700, бензин 1900» → «Сохранить расшифровку» → открой Чат:
  увидишь надиктованное сообщение с предложением «Смена» → «Записать смену» → деньги записаны.
  (С запущенным `npm run whisper-server` тот же путь идёт от реального голоса.)
- Долг: сущности эмоции/теги из транскрипта — позже; надёжность реального демона под
  нагрузкой — среда-флейк, см. LESSONS.md.
